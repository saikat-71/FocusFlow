# FocusFlow – Personal Productivity & Life Tracker

FocusFlow is a beginner-friendly personal productivity and life tracking web application. It helps users organize daily tasks, monitor how they spend their time, track personal goals, and understand their productivity through a simple dashboard.

## Features

### 1. Dashboard
- Daily productivity overview
- Completed task statistics
- Productive and unproductive time summary
- Goal progress overview
- 7-day productivity chart
- Time breakdown by category

### 2. Task Management
- Add, edit, and delete tasks
- Mark tasks as completed
- Set task date and time
- Set priority levels (High, Medium, Low)
- Organize tasks by category
- Add location and notes
- Search and filter tasks

### 3. Time Tracker
- Start and stop a live timer
- Track activities by category
- Manually add activity records
- Record productive and unproductive time
- View and delete activity logs

### 4. Goal Management
- Create personal goals
- Set target and current progress
- Add deadlines
- Update and delete goals
- Monitor goal completion percentage

### 5. Additional Features
- Dark and light mode
- Responsive design for desktop and mobile
- Browser LocalStorage for data persistence
- Simple and beginner-friendly interface

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## How to Run

1. Download or clone this repository.
2. Extract the project folder.
3. Open the project folder.
4. Open `index.html` in your web browser.
5. Start managing your tasks, activities, and goals.

No backend server or additional installation is required.

## Data Storage

FocusFlow uses the browser's LocalStorage to save tasks, activities, goals, and application settings.

All data is stored locally in the user's browser. This version does not include user authentication or cloud synchronization.
